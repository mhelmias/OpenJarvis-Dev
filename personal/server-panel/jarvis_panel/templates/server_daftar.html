Kunci SSH panel

Supaya panel bisa masuk ke sebuah server, tambahkan kunci ini ke akun yang dipakai di server itu. Jalankan di server tujuan, sebagai akun tersebut:

mkdir -p ~/.ssh && chmod 700 ~/.ssh && echo 'restrict {{ pubkey }}' >> ~/.ssh/authorized_keys && chmod 600 ~/.ssh/authorized_keys

Saran: buat akun khusus tanpa sudo di server tujuan. Kata restrict mematikan penerusan port dan agen untuk kunci ini.
